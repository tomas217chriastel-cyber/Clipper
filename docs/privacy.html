AutoClipper – Privacy Policy

Last updated: November 18, 2026

AutoClipper is a desktop application that runs on the user's own computer. It watches live streams the user chooses, cuts short clips of exciting moments and, when the user asks it to, uploads those clips to the user's own YouTube or TikTok account. This policy explains what data the app handles.

1. Data the app uses

  • Stream video and public live chat of channels the user adds, used only to detect moments and create clips.
  • Clips the app creates, stored as files on the user's computer.
  • Account connection data when the user connects YouTube or TikTok: login tokens, and for TikTok the account's open ID, display name (nickname) and username, so the app can show which account a video will be posted to.
  • Video posting settings the user picks for each upload (caption, visibility, interaction and disclosure options).

2. How data is used

Data is used only to provide the app's features: creating clips and uploading or posting the clips the user selects to the account the user connected. Nothing is posted without the user starting the upload.

3. Where data is stored

All data, including login tokens, stays on the user's own computer, in the app's local data folder. The developer runs no server and does not receive, collect, sell or share any user data. There are no analytics, ads or trackers.

4. Data sent to third parties

When the user uploads a clip, the video file and the chosen post details are sent directly from the user's computer to the platform the user selected (YouTube or TikTok), under that platform's own terms and privacy policy.

5. Removing data and revoking access

The user can disconnect an account at any time with the app's Disconnect button, which deletes the stored token (and for TikTok also revokes it). Access can also be removed in the platform's own settings. Deleting the app's data folder removes all stored data.

6. Children

AutoClipper is not directed at children under 13 (or the minimum age required by the platform used).

7. Changes

Updates to this policy are published on this page with a new date.
