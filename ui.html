YouTube account
One-time setup (about 10 minutes). Google requires you to create your own free “OAuth client”:
  1. Open the Google Cloud Console and create a project.
  2. APIs & Services → Library → enable YouTube Data API v3.
  3. OAuth consent screen: type External, fill app name + your email, add your own Google account as a test user, then click Publish app (otherwise the login expires every 7 days).
  4. Credentials → Create credentials → OAuth client ID → type Desktop app. Paste the Client ID and secret below.

TikTok account
One-time setup (about 10 minutes). TikTok requires you to create your own free developer app:
  1. Open the TikTok developer portal, log in and click Manage apps → Connect an app. Choose platform Desktop.
  2. Add the products Login Kit and Content Posting API (turn on Direct Post if you want to post without the TikTok app).
  3. In Login Kit add this redirect URI exactly: http://127.0.0.1:*/tiktok/callback/
  4. Add your own TikTok account under Sandbox → Target users (or submit the app for review), then copy the Client key and Client secret below.
Posting defaults
Drafts: TikTok notifies you in the app, you tap it, check and post. Works right away.
Direct: posts without opening TikTok. Until TikTok reviews your developer app, direct posts can only be “Only me”.
