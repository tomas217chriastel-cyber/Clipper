# Subtitle fonts

Bundled so subtitles look the same on every PC. All are licensed under the
SIL Open Font License 1.1 (see `OFL.txt`), which allows bundling them with software.

- `Anton-Regular.ttf` — Anton Regular. Copyright 2020 The Anton Project Authors (https://github.com/googlefonts/AntonFont.git)
- `ArchivoBlack-Regular.ttf` — Archivo Black Regular. Copyright 2017 The Archivo Black Project Authors (https://github.com/Omnibus-Type/ArchivoBlack)
- `BebasNeue-Regular.ttf` — Bebas Neue Regular. Copyright 2019 The Bebas Neue Project Authors (https://github.com/dharmatype/Bebas-Neue)
- `Montserrat-Black.ttf` — Montserrat Black. Copyright 2011 The Montserrat Project Authors (https://github.com/JulietaUla/Montserrat)
- `Montserrat-ExtraBold.ttf` — Montserrat ExtraBold. Copyright 2011 The Montserrat Project Authors (https://github.com/JulietaUla/Montserrat)
- `Poppins-ExtraBold.ttf` — Poppins ExtraBold. Copyright 2020 The Poppins Project Authors (https://github.com/itfoundry/Poppins)
